# 本机可视化控制台

## 0.21：全范围探测和 SNMP 配置

扫描设置新增“SNMP 配置”，当前页面支持用户要求的 SNMP v2c。填写新的只读团体名并保存，会用于下一次探测、完整采集及接口轮询；留空则保留现有值。页面只显示“已配置/未配置”，不回显已有团体名。原有按网段选择其他 profile 的规则保持有效，页面编辑默认采集 profile。

`PUT /api/settings` 可增加 `snmp: {"version":"2c","community":"新的只读团体名"}`，省略 community 或留空保留现有值，旧客户端完全省略 snmp 时保持兼容。community 是只写字段，不进入响应、scope、主配置、扫描摘要或日志。凭据独立保存在 config 下的 `.secret` 文件：Windows 使用当前运行用户 DPAPI，Linux 使用 0600 私有文件；不能直接把 Windows 加密文件复制到 Linux。主配置仅记录 community_file 路径，读取时优先于原 community_env；未通过页面修改时继续使用原环境变量。

一次更新会实际探测全部有效管理 IPv4 地址，不需要反复点击来推进 256 个地址的批次。探测和 LLDP 递归分别统计，停止/超时保留已完成结果，并显示尚未尝试的数量。保存设置本身不发起拓扑扫描。详见 [全范围探测说明](preprobe.md)。

控制台复用 GoNet 的 LLDP 采集器和现有 PostgreSQL 服务，不另建数据库。
页面、样式与脚本嵌入 Go 可执行文件，无 Node 运行要求、CDN 或外部前端服务。

## 管理员登录初始化

构建当前源码后，先在交互终端执行 `./gonet.exe auth hash-password`。输入并确认至少 12 个字符、最多 72 个 UTF-8 字节的密码；输出为 bcrypt cost 12 哈希，不接受明文参数或管道。妥善保存哈希，不将环境文件提交到仓库。

为 serve 配置 `GONET_ADMIN_USERNAME` 和 `GONET_ADMIN_PASSWORD_HASH`，没有默认账号。`GONET_SESSION_TTL` 默认为 `8h`，须大于 0 且不超过 `24h`。`GONET_COOKIE_SECURE` 默认为 `true`；本机回环 HTTP 开发必须显式设为 `false`，HTTPS 反向代理必须为 `true`。配置错误时在监听和配置保存前拒绝启动。其他采集/导出 CLI 不要求网页登录配置。

PowerShell 环境可用单引号包住 bcrypt 哈希，防止 `$` 被展开；start-ui 从已有进程环境优先读取认证变量，缺少时从 Windows 用户环境加载。不要把账号密码、哈希或会话写进脚本。已有运行实例不会被开发任务自动替换，发布前须备份旧二进制和非敏感配置基线。

浏览器先进入 `/login`，登录后可恢复 `/?page=topology` 等已知页面。Session 只保存在 HttpOnly / SameSite=Lax Cookie 中，服务端仅保存摘要；固定绝对有效期，不滑动续期。退出销毁当前会话，修改管理员环境并重启后全部旧会话失效。服务重启同样清空内存会话；其他浏览器的独立会话不会因单次退出或重新登录失效。

`GET /api/v1/auth/me` 检查 Session 并返回该会话 CSRF；`POST /api/v1/auth/login` 要求 JSON 与 `X-GoNet-Login: 1`；`POST /api/v1/auth/logout` 要求 Session 与 `X-GoNet-Token`。旧业务 API 保留合同，未登录为 401，已登录写请求须本会话 CSRF。403 和 503 不视为退出登录。所有响应禁止缓存，不允许跨源 CORS。

单一真实 socket 来源在 60 秒内累计失败 5 次后限速，返回 429 与 Retry-After；不信任 X-Forwarded-For。反向代理后的客户端共用回环来源限额，暂不支持可信代理地址解析。

## 打开与停止

```powershell
Set-Location E:\gonet.0
pwsh -NoProfile -File .\scripts\start-ui.ps1
```

浏览器访问 <http://127.0.0.1:8787>。脚本在后台启动本机进程并打开页面；
重复运行只打开已有控制台。`-NoBrowser` 不打开浏览器，`-Foreground` 在终端前台运行，
可用 Ctrl+C 停止。端口冲突时可使用 `-Port 8788`。默认只监听回环地址。

Windows 可通过本机文件 `config/console-listener.json` 指定内网 HTTPS 入口。将 `listen_host` 设为本机内网 IP，将 `allowed_sources` 设为逗号分隔的客户端 IP 或 CIDR 字符串，并通过 `tls_cert`、`tls_key` 和 `tls_ca` 指定 PEM 格式的服务器证书、私钥和用于健康检查的 CA 证书。GoNet 按 TCP 对端限制整个控制台的访问，API Key 仍独立校验白名单。Windows 防火墙应匹配同一监听地址、端口和客户端来源。浏览器及停止脚本使用系统证书信任；自动化客户端可直接指定 CA 文件。

```powershell
pwsh -NoProfile -File .\scripts\stop-ui.ps1
```

停止脚本核验进程路径及启动时间，只停止记录中的 GoNet 控制台；扫描中先请求取消。脚本隐藏交互输入管理员密码，Cookie 仅留内存，结束前注销短期使用的会话；认证失败或无法确认任务状态时拒绝停止。Secure Cookie 部署使用 `-BaseUrl https://你的可信站点:8443`（不跳过 TLS 验证）。
关闭浏览器页面不会停止后台进程，也不会停止 PostgreSQL 服务。

1. **总览**显示已确认设备总数，并单独统计交换机、路由器、无线 AC；物理链路、本轮采集与历史设备数量，以及未知邻居分别显示。
2. **设备列表**可搜索设备名、IP、Chassis，按厂商、设备类型及采集状态筛选，导出当前筛选的 CSV（含设备类型）。
   名称与型号分列，长名称悬停查看；列表只显示一个管理地址，点击详情查看全部地址、身份、网络层级、相邻设备和具体端口。
3. **拓扑视图**默认显示从核心向下的全网分层拓扑。可切换邻接视图、搜索名称/IP定位、缩放/拖动、折叠分支、适应/重置与全屏。
   两端间的并行物理链路聚合显示数量；详情中仍保留每条物理链路。
4. **更新拓扑**依次显示网段预探测、核心采集、邻居匹配/递归、保存，可停止并保留已完成的正面事实。
   页面和命令行共用数据库扫描锁，已有任务运行时不会再并发扫描。
5. **未知邻居**单独保留未知型号、无访问通道等 LLDP 观察，不当作新增交换机台数。
6. **SNMP 探测池**显示访问 IP、名称/型号证据、本机 Chassis、成功/尝试时间、范围与缓存状态、真实设备 ID、未关联原因及下轮动作，支持搜索、分页和 JSON 导出。

路由器 / 无线 AC 必须有支持的精确型号规则或明确人工覆盖，并通过直接采集核验；不会

不计作正式物理链路或已确认设备；普通 AP、电话、终端继续排除。

设备数依据核验后的 Chassis / device_id 去重。TS7914 双机堆叠为一个逻辑节点。

## 管理 IP 段、排除与发现起点

进入“扫描设置”，按以下顺序操作：

1. 在“管理 IP 段”添加授权 CIDR，单个 IP 自动规范化为 /32（IPv6 交后端校验）。重复或新重叠段就地提示，不自动扩大范围。
2. 点击某段的“管理排除 / N 个排除”，在抽屉中添加、删除单个排除 IP。排除项优先于允许段；收窄/删除网段不会静默删除旧排除。
3. 段外或旧 CIDR 排除保留在“历史排除记录”，可以显式删除并撤销。大网段不会展开成大量单 IP。
4. 在“发现起点”添加每轮实际采集的单个 IP，必须位于允许范围且未被排除；至少保留一个起点。
5. “保存设置”只保存；“保存并更新拓扑”先保存成功，再调用普通更新。保存失败不扫描；保存成功但扫描启动失败时，可“仅重试扫描”。

设置页的“保存”属于表内修改或页面设置保存，不会隐式增加额外起点或访问范围。
顶部“更新拓扑”遇到未保存草稿时会引导回设置。扫描期间禁用范围修改，后端扫描锁继续生效。
本机配置保留单个核心 `10.201.1.1`、3 个 /24 与两个 /32，预探测有效主机 **764**；
段外旧排除 `10.201.1.2/32` 作为历史排除保留。689 是探测池已有地址条数，不是允许访问主机总数。

普通更新先按 `discovery.preprobe` 的批量、时间和全局预算探测有效允许范围，再从核心沿 LLDP
匹配和递归。新增设备只有经过身份、型号与物理端口核验，才进入正式拓扑。没有 LLDP 路径的独立区域
需要一个明确的发现起点；允许段本身不会变成额外起点。既有排除范围继续生效。

型号未知、SNMP 不可达、LLDP 未启用或端口映射有歧义时，保留待核验项。
标准 LLDP 管理地址、历史已核验地址和 `identity.address_overrides` 都只是访问通道。
“读取标准 LLDP 管理地址”开关保留；它不让 IP 参与身份匹配。

## Windows 本机加密配置

本机部署通过 `config/console-auth.dpapi.xml` 保存当前Windows用户DPAPI保护的bcrypt哈希，文件已忽略提交。start-ui.ps1先读取进程/Windows用户认证环境，缺少的值再从此文件加载；无效格式或非加密摘要会拒绝启动。文件仅包含版本1和Environment字典，字段限定为已有GONET认证变量；PASSWORD_HASH及可选AGENT_READ_TOKEN_SHA256必须为SecureString。密码明文不会写入该文件，扫描设置不会覆盖它。

修改哈希前先用 `gonet auth hash-password` 交互生成新哈希，再用同一Windows账户以SecureString更新文件并安全重启。此次初始短口令是用户指定的一次性初始化例外，标准初始化仍要求至少12字符。直接运行serve仍需要环境变量，使用本机start-ui脚本可自动解密加载。
