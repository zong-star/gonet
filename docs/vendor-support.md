# 设备支持与识别规则

设备分类规则位于 `config/device_rules.yaml`，物理端口兼容规则位于 `config/port_rules.yaml`。规则通常同时要求产品 OID、准确型号和固件描述匹配，不按厂商统一放行。

当前规则包含部分 H3C S5560X、S5130S、S5120/V2、S3100/V2/V3、MS4200，以及部分华为 S5735、S5720、S2700、S2318 和无线控制器的限定型号/固件。以实际规则文件为准；型号识别成功不表示该设备的所有 LLDP/IF-MIB 数据都能完整采集。

S5120V2-28P-SI 的 Release 6126P20 和 6318P01 分别采用精确规则。6318P01 需要产品 OID `1.3.6.1.4.1.25506.1.1678`，不会泛化到相近产品或其他固件。

信锐 TS7914 和部分 RS 固件使用显式适配器。厂商企业 OID 或通用 Linux 描述不足以证明型号；部署者需要核实自己的设备和固件指纹，按需配置身份或端口覆盖。

## 新增支持

1. 在授权范围内取得系统 OID、系统描述、本端和远端 LLDP 表、IF-MIB 及同一时间段的 CLI LLDP 对照。
2. 对管理 IP、设备名、MAC 与接口描述作全局一致脱敏，保留 subtype、字节长度、索引、端口对应关系和并行链路。
3. 在 `testdata/adapters/` 添加最小可复现 fixture，注明实际支持范围和限制。
4. 新增精确规则，并测试正例、相近型号、其他固件及 OID 数字段边界。
5. 验证分类、端口匹配与双向连接，缺失证据继续保留为待核验状态。

修改识别规则不需要重新编译，新一轮扫描会加载规则。不要使用名称或访问 IP 伪造 Chassis 身份。
